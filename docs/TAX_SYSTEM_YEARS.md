# إصدارات النظام الجبائي السنوية (Tax System Years)

> أُضيفت في جلسة 2026-08-04 (v3.1.8) — مواكبة نشرة DGI الرسمية 2026.

## الفكرة

النظام الجبائي الجزائري يُحدَّث سنوياً عبر القانون المالي ونشريات المديرية العامة للضرائب (DGI).
بدلاً من تعديل ملف `tax_config.json` الوحيد يدوياً مع كل تغيير، يخزّن التطبيق **ملف إعدادات لكل سنة**
منفصلاً، مع **تبديل سنة» من داخل الواجهة** مباشرة.

```
modules/config_years/
├── tax_config_2025.json      # نسخة مرجعية (مطابقة لـ tax_config.json القديم)
├── tax_config_2026.json      # وفق نشرة DGI 2026 (شرائح IRG مصححة + أقسام جديدة)
├── .active_year              # مؤشر السنة النشطة الحالية (مثال: 2026)
…
```

## كيف تعمل؟

1. عند الإقلاع أو أي حساب ضريبي، يحمّل `TaxEngine` إعدادات السنة النشطة من `config_years/`.
2. لو غابت سنة/ملف، يرجع المحرك إلى `tax_config.json` القديم (توافق رجعي كامل).
3. أي ملف سنة يُدمج **عميقاً** مع الإعدادات الافتراضية (`TaxEngine._deep_merge`) —
   فملف سنة قديم بلا الأقسام الجديدة (IFU/التكوين/الاقتطاع) يحصل عليها تلقائياً دون كسر الحسابات القديمة.

## واجهة «سنوات النظام» (تبويب جديد في شاشة الضرائب)

- **قائمة السنوات المتوفرة + زر «تفعيل»**: تبديل السنة النشطة فوراً.
- **زر «إضافة سنة»**: نسخ أحدث سنة إلى سنة جديدة (رسومية عبر مربع إدخال) — ثم تعديل مباشر.
- **زر «حذف»**: حذف سنة (بشرط ألا تكون السنة الأخيرة الوحيدة).
- **محرر JSON**: يَعرض إعدادات السنة الحالية؛ أزرار تحميل / تحقق / حفظ / استيراد من ملف / تصدير إلى ملف.
  زر «تحقّق» يستدعي `tax_years.validate_year_config()` ويعرض قائمة الأخطاء.
- **حاسبات النظم الجديدة**: IFU + رسم التكوين/التمهين + الاقتطاع من المصدر على الإيجارات.

## ما الجديد وفق نشرة DGI 2026؟

### 1. شرائح IRG السنوية (إصلاح — كانت خاطئة)
| الشريحة | الحد الأدنى | الحد الأقصى | النسبة |
|--------|-----------|-----------|--------|
| 1 | 0 | 240,000 | 0% |
| 2 | 240,001 | 480,000 | 23% |
| 3 | 480,001 | 960,000 | 27% |
| 4 | 960,001 | 1,920,000 | 30% |
| 5 | 1,920,001 | 3,840,000 | 33% |
| 6 | 3,840,001 | ∞ | 35% |

(القديم: 0/20/30/35% بحدود 120k/360k/1440k — غير مطابق للنشرة.)

### 2. IFU — الضريبة الجزافية الوحيدة (`calculate_ifu`)
- **0.5%** نظام المقاول الذاتي (رقم أعمال ≤ 5M دج، حد أدنى 10,000 دج)
- **5%** إنتاج وبيع السلع
- **12%** الأنشطة الأخرى — حد أدنى إجمالي 30,000 دج
- شرط: رقم الأعمال السنوي ≤ 8M دج.
- إعفاءات: الترقية العقارية، الاستيراد لإعادة البيع، بيع الجملة، العيادات، المخابر، الإطعام المصنف، الأشغال العمومية، وكالات السياحة…

### 3. رسم التكوين المهني + رسم التمهين (`calculate_formation_tax`)
- **1% + 1%** من كتلة الأجور الخام.
- المستحق = (1% من الكتلة − ميزانية التكوين المنفقة فعلياً) — إنفاق أكبر صفرية.

### 4. الاقتطاع من المصدر على إيجارات الملكيات (`calculate_rental_withholding`)
| النوع | النسبة |
|------|--------|
| سكني | 7% |
| تجاري | 15% |
| مهني | 15% |
| فلاحي | 10% |
| أراضٍ غير مبنية | 15% |
- إيجار سنوي > 1,800,000 دج ⇒ اقتطاع مؤقت 7% ريثما تُصفّى القيمة.

### 5. إعفاءات 2026 (موثّقة في القسم `exemptions_2026`)
- علامة «مؤسسة ناشئة»: 4 سنوات (قابلة للتمديد).
- الحاضنات (incubators): سنتان.
- ولايات الجنوب: تخفيض 50% اعتباراً من 01/01/2025.
- أنظمة دعم التشغيل (ANSEJ/CNAC/ANGEM): من 3 إلى 6 سنوات.

## واجهة برمجية

```python
from modules import tax_years
from modules.tax import TaxEngine

tax_years.list_years()            # [2025, 2026]
tax_years.get_active_year()       # 2026
tax_years.set_active_year(2026)   # True
tax_years.load_year(2026)         # dict | None
tax_years.save_year(2026, config) # True/False
tax_years.copy_year(2026, 2027)   # نسخ سنة كاملة
tax_years.delete_year(2025)       # True/False
tax_years.validate_year_config(d) # list[str] (أخطاء التحقق)
tax_years.import_year_from_json(s)# (data, errors)
tax_years.export_year_to_json(y)  # str | None

engine = TaxEngine(year=2026)     # تحميل إعدادات سنة محددة مباشرة
engine.set_year(2027)             # تبديل لاحق — bool
engine.calculate_ifu(turnover, "auto")
engine.calculate_formation_tax(payroll, f_budget, a_budget)
engine.calculate_rental_withholding(amount, "commercial")
```

## التحقق من سلامة ملف السنة (`validate_year_config`)
يُتحقق من وجود: `ibs`, `tva`, `irg` (بشرائح تصاعدية), `cnas`, `cnac`,
`versement_forfaitaire`, `ifu` (معدلات + حد أدنى)، وتناسق ترتيب/نِسَب شرائح IRG.

## التحديث السنوي (خلاق)
1. افتح شاشة الضرائب ← تبويب «سنوات النظام».
2. زر «إضافة سنة» ← ستُنسخ السنة الأحدث تلقائياً.
3. عدّل المبالغ/النسب في محرر JSON حسب نشرة DGI الجديدة.
4. اضغط «تحقّق» (يخطئ إن نُسيت شريحة/مفتاح)، ثم «حفظ».
5. اضغط «تفعيل» لبدء استخدامها.

بديل كامل للاعتماد اليدوي: **استيراد JSON** من ملف موثّق خارجي.
