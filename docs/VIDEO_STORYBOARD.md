## Overlay Style Guide

### Text Overlay Rules
- **Font:** Montserrat Bold (or system sans-serif)
- **Color:** White (#FFFFFF) with 60% black shadow
- **Position:** Bottom-center for captions, top-right for shortcuts
- **Duration:** 2–3 seconds per overlay
- **Animation:** Fade in 0.3s, hold, fade out 0.3s

### Keyboard Shortcut Overlay
```
┌─────────────┐
│  Ctrl+R     │  ← large, bold
│  Calculate  │  ← smaller, regular
└─────────────┘
Position: Top-right corner
Background: Semi-transparent black (80%)
```

### Section Title Overlay
```
┌──────────────────────────────────────┐
│  SECTION 3: DATA ENTRY              │  ← all caps
│  Ctrl+1                              │  ← shortcut
└──────────────────────────────────────┘
Position: Bottom-left
Background: Brand blue (#1F4E79)
Duration: 3 seconds
```
