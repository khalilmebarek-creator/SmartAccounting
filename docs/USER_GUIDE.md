## 2. الميزات الجديدة (جلسة v3.1.6)

### 2.1 تحسين الأداء الشامل (v3.1.6)
- إقلاع أسرع ~15× (778 → 49ms) وذاكرة أقل (128 → 45MB).
- تحميل كسول للشاشات والوحدات + تجمّع اتصالات قاعدة البيانات.
- حفظ/قراءة أسرع بنحو 5×–17×.

### 2.2 تعدد العملات (شاشة 26)
1. افتح **تعدد العملات** (F7) وحدّد العملة الأساسية (دج افتراضياً).
2. أضف عملات (دولار/يورو/…) مع سعر الصرف.
3. استخدم المحوّل المباشر أو تقرير العملات متعدد العملات مع تصدير CSV.

### 2.3 المزامنة السحابية والنسخ الاحتياطي (شاشة 27)
- أضف وجهة (مجلد Dropbox/OneDrive/Drive محلي).
- فعّل "نسخ احتياطي تلقائي" — يُنشئ snapshot مع checksum.
- فعّل **التشفير بكلمة مرور** (AES-GCM) للحساسية.
- استرجاع: اختر snapshot ثم **سحب** أو **استرجاع**.
- كل العمليات تُسجَّل في سجل داخل قاعدة البيانات.

### 2.4 الشركات التجريبية (شاشة 28)
- 4 شركات: تجارية / خدمات / إنتاج / استيراد-تصدير.
- **تحميل الشركة** يعبّئ التطبيق ببيانات مالية وضريبية متسقة + 12 شهر معاملات.
- **تصدير CSV** للبيانات، وقوالب استيراد متوافقة مع شاشة الاستيراد.

### 2.5 اختبار المستخدمين (شاشة 29)
1. أنشئ جلسة: الاسم، المختبر، المجموعة (مدير/محاسب/مستخدم عادي/صاحب قرار)، السيناريو.
2. أضف ملاحظات بتصنيف (خلل/اقتراح/تعقيب…) وأولوية وحالة.
3. انظر درجة الرضا والتحليل التفصيلي (حسب التصنيف/المجموعة/السيناريو).
4. تقارير: **تعقيبات** / **قائمة أعطال** / **طلبات تحسين** / **ملخص**.
5. **حفظ/تحميل DB** يخزّن الجلسات في قاعدة البيانات، والتصدير يدعم JSON/Excel/PDF/CSV.

### 2.6 تحسينات UI/UX
- اختصارات كاملة (أعلاه)، قائمة "عرض"، رسائل خطأ موحّدة مع إجراء مقترح، انتقالات تلاشي، مؤشر تحميل، وتحسينات تباين/إتاحة في الثيمات الثلاثة.

### 2.7 الشاشات المحاسبية المتقدمة (شاشات 30-35) — جلسة v3.1.7
1. **دفتر الأستاذ (30)** — ميزان مراجعة + تصفح القيود والسجلات بالتخصيص حسب التاريخ/الحساب.
2. **حسابات الأطراف (31)** — إدارة العملاء/الموردين + تقرير تقادم الديون (أقل من 30/60/90/أكبر).
3. **الفواتير (32)** — إنشاء/تعديل فواتير البيع والشراء مع حساب TVA وحالة الدفع (مدفوعة/غير مدفوعة/جزئية).
4. **المخزون (33)** — جرد الأصناف + تقييم بمتوسط التكلفة المرجح + تنبيهات النفاد.
5. **الرواتب (34)** — رواتب الموظفين + الحسابات الاجتماعية (CNAS موظف/صاحب عمل) + IRG الشهري.
6. **الميزانية التفصيلية (35)** — بنود/فئات (مصروف/إيراد/استثمار) + مقارنة المخطط بالفعلي + الانحرافات + تصدير CSV + حفظ DB.

> تمت إضافة المحرّكات الستة في `modules/`: `ledger.py` + `partners.py` + `invoicing.py` + `inventory.py` + `payroll.py` + `budgeting.py`.

## 3. أفضل الممارسات

### إدخال البيانات
1. احرص على توازن الميزانية: **الأصول = الالتزامات + حقوق الملكية** (يرفض النظام الإدخال غير المتوازن).
2. أدخل الأرقام كاملة (دج) دون فواصل — الحقول تقبل الأرقام فقط.
3. استخدم **إدخال البيانات** أولاً ثم انتقل للتحليل؛ البيانات محفوظة في قاعدة البيانات.

### التحليل المالي
4. ابدأ بـ **النسب المالية** ثم **DuPont** لفهم محرّكات العائد على حقوق الملكية.
5. استخدم **التدقيق** قبل أي تقرير نهائي — يلتقط الأخطاء قبل تصديرها.
6. في **المعايير المرجعية** اختر القطاع الصحيح؛ التغيير يحدّث النتائج فوراً.
7. لاتخاذ قرار طويل المدى: **Z-Score** (الإفلاس) + **التنبؤ** (نمو) + **السيناريوهات** (مخاطر).

### الضرائب الجزائرية
8. حدّث **سنة الضريبة** من شاشة الضرائب قبل المحاكاة (تغيير الفئة/النسب من `modules/tax_config.json`).
9. استخدم **تقويم الالتزامات** شهرياً: TVA (يوم 20)، IBS أقساط (3/6/11).
10. صَدّر إقرارات **G50/G57/DAS** من تبويب "الإقرارات" (PDF/Excel).

### النسخ الاحتياطي
11. فعّل **النسخ الاحتياطي التلقائي** في شاشة المزامنة — كل ما تحتاجه إعداد وجهة واحدة.
12. جرّب **الاسترجاع** من نسخة تجريبية قبل الاعتماد عليه في الطوارئ.
13. عند الترقية، يبقى نسخة من المثبّت القديم للتراجع (auto-update يحتفظ بها).

## 4. استكشاف الأخطاء وإصلاحها (Troubleshooting)

| المشكلة | السبب المحتمل | الحل |
|---------|---------------|------|
| رسالة "An Application Control policy has blocked this file" عند فتح التطبيق | Smart App Control في Windows 11 يحجب الـ exe غير الموقّع | شغّل `tools\allow_smart_app_control.ps1` كمسؤول (يفحص الحالة + يضيف استثناء Defender)، أو: Windows Security ← App & browser control ← Smart App Control ← Off |
| نافذة cmd تومض أثناء التحديث | التحديث عبر wscript/VBS (قديم) | حمّل آخر إصدار — التحديث الجديد مخفي تماماً |
| التطبيق لا يفتح بعد تحديث | نسخة قديمة بتوابع ناقصة (matplotlib) | أعد التشغيل أو استرجاع النسخة المحفوظة |
| أرقام لا تظهر بشكل صحيح في الطرفية | ترميز cp1252 | ضع `$env:PYTHONIOENCODING="utf-8"` قبل التشغيل |
| تصدير PDF يظهر رموزاً | غياب خط عربي (Amiri) | فعّل الخط من التطبيق أو ثبّت Amiri؛ عند غيابه يُستخدم بديل Latin-1 |
| زر تصدير لا يستجيب | مسار غير قابل للكتابة | اختر مساراً صالحاً؛ الخطأ يعرض رسالة موحّدة مع إجراء مقترح |
| البيانات لا تُحفظ | قاعدة البيانات مقفلة من عملية أخرى | أغلق التطبيقات الأخرى ثم أعد المحاولة |
| صعوبة في اختصارات F2-F12 | الشاشات 21-35 تُفتح من السايدبار أيضاً | استخدم السايدبار أو Ctrl+Shift+A للشركات التجريبية وCtrl+Shift+B/C/D لشاشات 33-35 |

> ملاحظة Smart App Control: يحجب Windows 11 الـ exe غير الموقّع رقمياً على بعض الأجهزة. الحل العملي للمستخدمين — `tools\allow_smart_app_control.ps1` كمسؤول (يفحص الحالة ويضيف استثناء Defender)، أو إيقاف الميزة من أمان Windows. التطبيق يدعم Windows 10 و11.

## 5. الأسئلة الشائعة (FAQ)

**س: هل أحتاج تثبيت Python لاستخدام المنصة؟**
لا — النسخة المثبّتة/المحمولة تعمل بدون Python (Nuitka onefile).

**س: أين تُحفظ بياناتي؟**
في `accounting_platform.db` داخل مجلد التطبيق، مع نسخ احتياطية في `backups/`.

**س: كيف أبدّل اللغة أو الثيم؟**
من **الإعدادات** (Ctrl+7): اللغة (AR/EN/FR) والثيم (فاتح/داكن/حديث) + **Ctrl+T** للتبديل السريع.

**س: كيف أجرب المنصة بأرقام واقعية؟**
شاشة **الشركات التجريبية** (Ctrl+Shift+A): حمّل إحدى الشركات الأربع وستجد تقارير جاهزة.

**س: هل تدعم المنصة الضرائب الجزائرية؟**
نعم: IBS + أقساط، TVA (19%/9%/0% + نسب خاصة)، IRG، CNAS/CNAC، DAS، وإقرارات G50/G57/DAS.

**س: كيف أنقل بياناتي إلى جهاز آخر؟**
من **المزامنة السحابية**: أنشئ snapshot وصدّره، أو استخدم النسخ الاحتياطي مع الاسترجاع على الجهاز الجديد.

**س: كيف أوثّق ملاحظات المختبرين؟**
شاشة **اختبار المستخدمين**: جلسة لكل مختبر + ملاحظات مصنّفة + درجة رضا + تصدير PDF/Excel لاجتماعات القبول.

**س: ماذا تعني درجة Z-Score؟**
أقل من 1.81 خطر إفلاس مرتفع، بين 1.81–2.99 منطقة رمادية، أكثر من 2.99 آمن.

**س: كيف أعرف أنني أحدّث التطبيق؟**
يفحص التطبيق تحديثاً تلقائياً عند التشغيل ويعرض نافذة عند التوفّر؛ التحديث يُحمَّل ويُطبَّق بلا نافذة cmd.
